# SIPERSAR — Frontend

Sistem Permintaan Usulan Kebutuhan Sarana dan Prasarana SAR · Direktorat Sarana dan Prasarana Basarnas.

Frontend statis (HTML/CSS/JavaScript murni) untuk GitHub Pages. Backend: Google Apps Script (REST API).

- Isi `GAS_URL` di `js/config.js` dengan URL Web App `/exec` sebelum push.
- Ekspor/impor Excel memakai `js/xlsx-lite.js` (tanpa pustaka eksternal).
- Panduan lengkap: `PANDUAN-INSTALASI.md`.
